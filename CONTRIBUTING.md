# Contributing to Suohai

Contributions are welcome. Please open an issue to discuss larger changes before submitting a pull request.

## Development

1. Fork and clone the repository:

   ```sh
   git clone https://github.com/lbenicio/suohai.git
   cd suohai
   ```

2. Create a focused branch and make your changes.
3. Run the relevant checks:

   ```sh
   make test
   make build
   ```

4. Submit a pull request with a clear description and any relevant test results.

For packaging changes, `make dmg` creates `.build/Suohai.dmg`.

Please follow the [Code of Conduct](CODE_OF_CONDUCT.md). Report security issues privately using the process in [SECURITY.md](SECURITY.md), rather than filing a public issue. General questions can be sent to [hi@lbenicio.dev](mailto:hi@lbenicio.dev).
